## Overview

This substep sets up the containerization for the entire stack. We will create a `Dockerfile` for the backend (frontend will run locally for dev or use a separate Dockerfile if needed, but typically we use `npm run dev` locally and Docker for services). However, for a complete local dev environment that mimics production, we will define services for Backend, PostgreSQL, and Redis in `docker-compose.yml`.

## Implementation

### Goal
Run the backend, database, and cache services using a single `docker-compose up` command.

### Step-by-Step Instructions

#### Step 1: Create Backend Dockerfile
- [ ] Copy and paste code below into `backend/Dockerfile`:
```dockerfile
FROM python:3.9-slim

WORKDIR /app

ENV PYTHONDONTWRITEBYTECODE 1
ENV PYTHONUNBUFFERED 1

# Install system dependencies
RUN apt-get update && apt-get install -y \
    build-essential \
    libpq-dev \
    && rm -rf /var/lib/apt/lists/*

# Install python dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application code
COPY . .

# Run the application
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]
```

#### Step 3: Create Docker Compose File
- [ ] Copy and paste code below into `docker-compose.yml` (in project root):
```yaml
version: '3.8'

services:
  backend:
    build: ./backend
    container_name: hdb_backend
    command: uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
    volumes:
      - ./backend:/app
    ports:
      - "8000:8000"
    environment:
      - POSTGRES_SERVER=db
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=postgres
      - POSTGRES_DB=hdb_buyer
      - DATABASE_URL=postgresql+asyncpg://postgres:postgres@db/hdb_buyer
    depends_on:
      - db
      - redis

  db:
    image: postgres:15-alpine
    container_name: hdb_db
    volumes:
      - postgres_data:/var/lib/postgresql/data
    environment:
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=postgres
      - POSTGRES_DB=hdb_buyer
    ports:
      - "5432:5432"

  redis:
    image: redis:7-alpine
    container_name: hdb_redis
    ports:
      - "6379:6379"

volumes:
  postgres_data:
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Port conflict | Ensure ports 8000, 5432, 6379 are free. |
| Database connection error | Ensure `backend` service waits for `db` (depends_on is set, but sometimes app starts too fast; retry logic in code handles this usually, or wait a few seconds). |
| Docker permission denied | Run with `sudo` or check Docker user group settings. |
