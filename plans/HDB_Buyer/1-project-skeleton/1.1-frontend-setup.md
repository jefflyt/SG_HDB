## Overview

This substep establishes the frontend foundation using Next.js 14 (App Router). We will initialize the project, configure Tailwind CSS for styling, and set up shadcn/ui for our component library. This creates the "Client" part of our architecture.

## Implementation

### Goal
Create a runnable Next.js application in the `frontend` directory with Tailwind CSS and shadcn/ui configured.

### Step-by-Step Instructions

#### Step 1: Initialize Next.js Project
- [ ] Run the following command to create the Next.js app non-interactively:
```bash
npx create-next-app@latest frontend --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --no-git
```

#### Step 2: Install shadcn/ui Dependencies
- [ ] Navigate to the frontend directory:
```bash
cd frontend
```
- [ ] Initialize shadcn/ui (this creates `components.json` and updates `tailwind.config.ts`):
```bash
npx shadcn-ui@latest init
```
*Note: When prompted, select "Default" style, "Slate" base color, and "yes" for CSS variables.*

- [ ] Since we are automating, we can manually create `components.json` instead of running the interactive init if preferred, but running the command is standard. If you want to force it, create `components.json` first:

- [ ] Copy and paste code below into `frontend/components.json`:
```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "default",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.ts",
    "css": "src/app/globals.css",
    "baseColor": "slate",
    "cssVariables": true,
    "prefix": ""
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"
  }
}
```

- [ ] Install the core utility library:
```bash
npm install clsx tailwind-merge class-variance-authority lucide-react
```

#### Step 3: Create Utility Helper
- [ ] Create the utility file required by shadcn/ui:
- [ ] Copy and paste code below into `frontend/src/lib/utils.ts` (create directory if needed):
```typescript
import { type ClassValue, clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `npx create-next-app` fails | Ensure you have Node.js 18.17+ installed. Check with `node -v`. |
| `shadcn-ui init` fails | Ensure `tsconfig.json` exists and `baseUrl` is set to `.` and `paths` includes `@/*`. |
| Styles look broken | Verify `tailwind.config.ts` content paths match your folder structure (`src/app`, etc.). |
